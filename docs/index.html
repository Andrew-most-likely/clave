A complete desktop for Hyprland.

Clave turns Hyprland on Arch Linux into a finished desktop: a menu bar, a Dock, Overview, Control Center, System Settings and a set of standard apps, with tiling kept. It installs hardened by default, works offline, and runs nothing in the background that it does not need.

$bash <(curl -fsSL https://raw.githubusercontent.com/Andrew-most-likely/clave/main/setup.sh)

Tour

Everything a desktop needs, drawn in one style.

The shell is built with Quickshell and Hyprland's Lua config. It is standalone and needs no other dotfiles pack. Pick a part to see it.

Watch the tour

Twenty seconds on a fresh install: Overview, Control Center, Apps, System Settings and a window minimized to the Dock.

Recorded in a virtual machine with software rendering, so animations run at a lower frame rate than on real hardware.

Features

Built in, and costs nothing when off.

Each feature is a setting in System Settings. A feature that is turned off starts no process and uses no memory.

Menu bar

The System menu, the app menu, battery, network, sound and the clock. One menu bar per screen.

Dock

Magnification, running indicators, pinning, and a genie minimize animation drawn with GLSL shaders.

Overview and Spaces

All windows at a glance, hot corners, and trackpad gestures to switch Spaces and open Apps.

Search and Apps

Find and open apps from the keyboard, with a calculator one key away that works offline.

Control Center

Wi-Fi, Ethernet, Bluetooth, Focus, brightness, volume, Night Light, media and screen mirroring.

System Settings

A pane for each part of the desktop, from Displays to Privacy & Security, with a search that finds the setting inside each pane.

Screenshots and recording

Print opens a toolbar for the screen, a window, an area or a recording. Shift+Print copies text from the screen.

Traffic-light title bars

Close, minimize and zoom buttons on every window, built from source for your Hyprland version.

Lock, login and boot

A lock screen with idle timeouts, an SDDM login screen and a Plymouth boot splash in the same style.

Apps

Standard apps, with plain names.

Clave installs a set of apps from the Arch repositories, with no background services. Only Weather, Maps and Podcasts go online, and only while open.

Notes, Calendar and Contacts are Clave's own. They keep your data as plain Markdown, .ics and .vcf files. No accounts and no sync: the files are yours.

Security

Hardened by default.

The hardening layer is part of the normal install. Skip it with --no-harden. If it ever locks you out, the recovery guide explains how to get back in.

Kernel

linux-hardened with lockdown, IOMMU and init_on_free flags, plus a sysctl lockdown.

Firewall

nftables drops all inbound traffic by default. OpenSnitch asks before apps connect out.

Mandatory access control

AppArmor with the apparmor.d profiles, and auditd.

Devices and logins

USBGuard, faillock, a stricter sudo, umask 027 at login and a noexec /tmp.

Integrity

An AIDE baseline and a daily arch-audit check for known vulnerabilities.

Disk Encryption

Clave says when the disk is not encrypted and guides the setup with LUKS2, as a reinstall or in place.

Updates

Safe on a rolling release.

Arch updates the software Clave depends on at any time. Each release lists the versions it was tested with, and Clave checks the machine against that list.

  • clave-doctor checks the Hyprland config, the plugins, the shell's log and each package Clave talks to. It uses no network.
  • A pacman hook warns after an upgrade that this release was not tested with, and never stops the upgrade.
  • A daily check on GitHub opens an issue when an Arch update breaks Clave.
  • Releases are signed, and clave-update installs only signed releases.
Install

Install in three steps.

On Arch Linux or an Arch-based distribution, as your normal user. The installer shows a summary and asks before it changes anything.

Run the setup script

It clones the latest release to ~/.local/src/clave and runs the installer. It is 40 lines; read it first if you like.

bash <(curl -fsSL https://raw.githubusercontent.com/Andrew-most-likely/clave/main/setup.sh)

Or clone it by hand

Preview every change with --dry-run first.

git clone https://github.com/Andrew-most-likely/clave ~/.local/src/clave
cd ~/.local/src/clave
./install.sh --dry-run
./install.sh

Log out and pick Hyprland

Choose Hyprland on the login screen. Update later from System Settings or with clave-update.

Installer options

OptionWhat it does
--yesNo questions. Hardening is included and its warning is printed.
--no-hardenSkip the security hardening layer.
--extrasAlso install the optional apps.
--personalUse fonts, a cursor and sounds you supply yourself.
--user-onlyOnly install files in your home folder. No sudo.
--no-packagesSkip pacman, AUR and Flatpak.
--dry-runShow what would happen and change nothing.

Uninstall

Every file the installer replaced comes back from the copy it kept. Packages stay installed.

~/.local/src/clave/uninstall.sh            # files in your home folder
~/.local/src/clave/uninstall.sh --system   # also login screen, boot splash, hardening

FAQ

Good to know.

Does Clave replace my existing Hyprland config?

The installer moves ~/.config/hypr and ~/.config/quickshell aside to a dated backup and keeps your monitors.lua, wallpapers and pinned Dock apps. uninstall.sh puts everything back.

Where do my own settings go?

In files the installer never replaces: ~/.config/hypr/custom.lua for any Hyprland setting, monitors.lua for screens, hypridle.conf for idle timeouts and ~/.config/clave/ for everything System Settings saves.

Does it work offline?

Yes. The desktop, Search and the calculator need no network. Online features are off by default.

What does the hardening change that I might notice?

USBGuard blocks USB devices that were not plugged in during the install. Three wrong passwords lock the account for 15 minutes. Keep a recovery USB; the recovery guide explains how to get back in.

Can I use my own logo, fonts or sounds?

Put an SVG at ~/.config/clave/branding/logo.svg for the menu bar, About window and boot splash. ./install.sh --personal uses fonts, a cursor and sounds that you supply yourself.

How do I report a problem?

Open an issue on GitHub and attach ~/.cache/clave/install.log and the output of clave-doctor.
